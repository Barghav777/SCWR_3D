# Script inventory

- `local_revision_audit.py`: audit source and derived data assumptions.
- `cpu_clean_benchmarks.py`: run clean CPU case-disjoint and diagnostic benchmarks.
- `ingest_kaggle_outputs.py`: ingest seed-specific Kaggle archives.
- `build_kaggle_clean_case_cv_notebook.py`: generate the resumable GPU notebook.
- `build_supplementary_pdf.py`: generate detailed main-text tables and the single supplementary PDF.

Run scripts from the repository root with Python 3.11+.
